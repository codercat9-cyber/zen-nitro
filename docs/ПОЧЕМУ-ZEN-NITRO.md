# Зачем нужен ZEN NITRO и чем он отличается от других клиентов

## Прежде всего — это исследовательский проект

ZEN NITRO — почти научный исследовательский проект. В его основе идея:
**изучать механизмы устойчивости связи, сами блокировки и способы их
обхода — на уровне клиента**, то есть в точке входа, там, где трафик
только рождается.

Серверную сторону изучают многие; клиент обычно остаётся «чёрной
коробкой»: нажал — получилось или нет. Мы делаем наоборот:

- **клиент как измерительный прибор.** Каждая попытка подключения — это
  опыт с записанными условиями: сеть, оператор, нода, ядро, режимы,
  ход событий по долям секунды и исход;
- **подробное журналирование** — «чёрный ящик» на телефоне и проверка
  линии с hex-дампом показывают, *где именно* и *как* гибнет трафик:
  на TCP, на приветствии TLS, после N килобайт;
- **гипотеза → проверка → вывод.** Каждое решение в коде опирается на
  журнал или живой замер, и в комментариях записано, на какой именно
  (дата, оператор, что увидели). Например, отпечаток для адресов
  Cloudflare выбран после замеров 14.10.2026, а отказ от Brutal на
  сотовой связи — после разбора журнала 20.10.2026;
- **устойчивость как предмет изучения**: каскады откатов, память «что
  работало на этом операторе», поведение при смене сети и сессии данных.

Работающий VPN-клиент здесь — одновременно и результат, и инструмент
исследования.

## Для чего

ZEN NITRO — клиент для Android, который поднимает защищённый туннель до
вашего сервера (или серверов из подписки) там, где интернет фильтруют:
ТСПУ, белые списки у мобильных операторов, подмена DNS, обрывы сессии
данных.

Сам по себе он **не продаёт серверы** и не ходит ни на какие свои узлы:
вы приносите подписку или ссылку, Zen делает всё, чтобы через неё был
интернет. Главная мысль проекта:

> **Работать в аварийных условиях, а когда не получается — честно сказать,
> почему.** Не «ошибка, попробуйте позже», а «до сервера доходит TCP, но
> приветствие TLS с этим именем глохнет — режут по SNI».

## Чем отличается

Большинство популярных клиентов построены вокруг **одного ядра** и одной
попытки: выбрал сервер — нажал — получилось или нет. Zen устроен иначе.

| | ZEN NITRO | Обычно у других |
|---|---|---|
| **Ядра** | sing-box, Xray и AmneziaWG (две ветки) в одном клиенте, каждое в своём процессе | одно ядро (Xray *или* sing-box); Amnezia — отдельным приложением |
| **Если нода не встала** | каскад откатов: снять подмену имени → убрать ByeDPI из цепочки → второе ядро → другая нода, причём сначала те, что **поднимались на этом же операторе** | ошибка, человек сам перебирает серверы |
| **Белые списки** | сам определяет «день белых списков», переключается на аварийные ноды, умеет подмену имени для нод за CDN | ручной выбор «WL-сервера» |
| **DNS** | шифрованный DoH **по IP** (без имени в рукопожатии), проверка подмены ответов оператором, последний проверенный адрес ноды на диске | системный DNS или один DoH по имени |
| **Подписки** | спрашивает панель «под разными клиентами» и сводит ответы: ссылки, base64, JSON Xray и sing-box, шаблоны Happ/Hiddify; сводит повторы и зеркала | понимает формат своего ядра |
| **ТСПУ и Cloudflare** | отдельный отпечаток для адресов Cloudflare (ТСПУ глушит «хромовое» приветствие с постквантовым ключом — проверено 14.10.2026) | один отпечаток на всё |
| **Сотовая связь** | щадящий пинг, подогрев и «встряска» радио на H/H+/E, сброс соединений ядра при новой сессии данных и смене сети, BBR вместо «вслепую» заявленной скорости Hysteria2 | настройки как для Wi-Fi |
| **Диагностика** | «чёрный ящик» на телефоне: каждая попытка с обстановкой и исходом; **проверка линии** — по ступеням с hex-дампом, где именно гибнет трафик | короткий лог в памяти |
| **Утечки** | броня: постоянный отпечаток устройства, IPv6 закрыт отказом, пароли на всех внутренних портах (приложения не вычислят VPN через 127.0.0.1), kill switch | по-разному, часто локальный SOCKS без пароля |
| **Обновления** | приложение и ядра — только по кнопке; модули ядер подписаны (ECDSA P-256), неподписанное не ставится; модуль, трижды не поднявшийся, снимается сам | ядра только с новой версией приложения |
| **Российские приложения** | одним нажатием мимо туннеля (банки, госуслуги, маркетплейсы) | ручной список |

## Где другие сильнее — честно

- **Платформы.** Zen сейчас только Android. Hiddify, Karing, INCY, Happ есть
  на iOS и компьютерах. Версия для Windows — в планах.
- **Зрелость и аудитория.** v2rayNG и Hiddify — открытые проекты с годами
  истории и тысячами пользователей; их баги находят быстрее.
- **Простота.** Zen показывает много подробностей. Кому нужна одна кнопка
  без журнала — тому проще в Happ.
- **Свои серверы.** Amnezia VPN умеет сама развернуть сервер на вашем VPS.
  Zen — только клиент.

## Кому он нужен

- Тем, у кого «всё работает дома, а на Tele2 / в метро / в регионе — нет».
- Тем, у кого несколько подписок от разных провайдеров и разных форматов.
- Тем, кто держит свои серверы и хочет понимать, **где** рвётся связь, —
  с журналом, который можно отдать администратору сервера.
